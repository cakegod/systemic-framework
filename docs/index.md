# Systemic Framework API

These guides describe the framework paths system authors use most often. They start at the host system context, then follow population data through access declarations, leases, range work, and scheduled changes.

## Guides

- [Use `SystemicSystemContext`](api/system-context.md) for host and Kernel operations during a system step.
- [Build populations and schedules](api/populations-and-scheduling.md) for generated columns, safe row access, and deferred population commands.
- [Read analyzer diagnostics](api/analyzers.md) for determinism and system-access rules, their activation, and their limits.

The [generated API reference](xref:Systemic.Kernel) includes XML documentation for Kernel, Core, the built-in module libraries, and the Kernel generator/analyzer. Contributor guidance explains which XML summaries are required and how to extend that checked surface.
